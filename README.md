# screenshotter (自動スクリーンショットツール)

PC画面（メインディスプレイ）を定期的に自動撮影し、軽量な画像ファイル（WebP形式）として保存するツールです。  
ゲームプレイの記録や作業ログの自動保存などに活用できます。

---

## 主な特徴

- **定期自動撮影**: 指定した秒数ごとに自動でスクリーンショットを保存します。
- **軽量・低負荷**: WebP形式で保存するため、PCの動作に負担をかけず、ディスク容量も節約できます。
- **かんたん操作**: バッチファイルをダブルクリックするだけでセットアップ・起動が可能です。

---

## はじめかた（初回セットアップ）

初回のみ、以下の準備を行います。

### 1. ツールのセットアップ (`run_setup.bat`)

1. フォルダ内にある **`run_setup.bat`** をダブルクリックして実行します。
2. 画面にインストールモードの選択が表示されたら、そのまま **`Enter`** キーを押してください（推奨設定の `[2]` が選ばれます）。
3. 「セットアップが正常に完了しました！」と表示されたら、何かキーを押してウィンドウを閉じます。

> [!NOTE]
> 実行時に「`uv がインストールされていないか、PATHが通っていません`」と表示された場合は、画面に表示される PowerShell コマンドを実行して `uv` をインストールした後、再度 `run_setup.bat` を実行してください。

### 2. 設定ファイルの作成 (`config.json`)

1. フォルダ内の **`config.sample.json`** をコピーします。
2. コピーしたファイルの名前を **`config.json`** に変更します。

---

## 使い方

### 起動方法
**`run_app.bat`** をダブルクリックします。  
黒い画面が開き、自動撮影が開始されます。

### 停止方法
開いている黒い画面上で **`Ctrl + C`** キーを押すか、右上の **「×」ボタン** でウィンドウを閉じてください。

### 保存先の確認
初期設定では、本ツールがあるフォルダ内の **`screenshots`** フォルダに `20261110161500.webp` （年月日時分秒）の形式で保存されます。

---

## 設定のカスタマイズ (`config.json`)

**`config.json`** をメモ帳などで開くことで、撮影間隔や保存先を自由に変更できます。

```json
{
  "interval_seconds": 5.0,
  "save_directory": "./screenshots",
  "quality": 80
}
```

### 各設定項目

| 項目名 | 説明 | 初期値 |
| :--- | :--- | :--- |
| `interval_seconds` | 撮影する間隔（秒）。小数を指定できます。 | `5.0` |
| `save_directory` | 画像の保存先フォルダ。相対パス・絶対パス（例: `D:/GameScreenshots`）のどちらも指定可能です。存在しないフォルダは自動作成されます。 | `"./screenshots"` |
| `quality` | 画像の品質（`1` 〜 `100`）。数値を上げると綺麗になりますが、ファイル容量が大きくなります。 | `80` |

※ 設定を変更した場合は、ツールを再起動すると反映されます。

---

## 注意事項・困ったときは

- **撮影される画面について**:  
  マルチモニター環境の場合、キャプチャされるのは「**メインディスプレイ**」のみです。
- **起動直後に閉じてしまう場合**:  
  - `config.json` が正しく作成されているか確認してください。
  - `config.json` 内のカンマの有無や数値の入力に誤りがないか確認してください。
  - 事前に `run_setup.bat` が正常完了しているか確認してください。
